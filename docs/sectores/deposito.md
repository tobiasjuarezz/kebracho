# Sector Depósito

Este QR está en la puerta del depósito. Resume cómo se maneja la mercadería.

## Qué se hace acá
- Guardar la mercadería: estanterías de latas, de botellas y de merchandising; bebida fría en las cámaras.
- Recibir a los proveedores y avisar a Administración para que actualice el stock.
- Avisar cuando falta mercadería.

## Relación con el sistema
- El stock se descuenta **solo** cuando un cliente confirma un pedido (dentro de una transacción).
- Si un pedido se cancela, el stock vuelve a sumarse.
- El stock físico tiene que coincidir con el del sistema: si no coincide, se avisa a Administración.
